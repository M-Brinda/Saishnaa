# Journal Papers Folder

Use this folder for uploaded journal PDF files.

Recommended structure:

```text
journal-papers/
  IJCSE/
    2026/
      volume-13/
        issue-5/
          IJCSE-V13I5P101.pdf
```

PDF URL to use in code:

```text
journal-papers/IJCSE/2026/volume-13/issue-5/IJCSE-V13I5P101.pdf
```

Naming format:

```text
JOURNALCODE-VOLUMEISSUEPAPER.pdf
```

Example:

```text
IJCSE-V13I5P101.pdf
```
